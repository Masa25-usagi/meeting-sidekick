# 会議の相棒 / MeetingSidekick

会議やライフログの音声を聞き、必要なときに会話・調査・思考・試作を始める、開発中のmacOSアプリです。常時の文字起こしを判断器に渡し、Gemini LiveやCodexなどを必要なときに呼び出します。コーディングエージェントは思考・計画・判断基準作りも担当します。

この公開リポジトリは、開発中アプリのソースコードを収録しています。APIキー、会話履歴、録音、個人設定、生成した試作品、実機スクリーンショット、既存の作業履歴は含めていません。

## 必要なもの

- macOS 15以降、Swift 6を利用できるXcode開発環境。
- 利用する音声・判断プロバイダーのAPIキー。モデル名は設定画面で変更できます。
- 思考・調査・制作を使う場合は、利用可能なCodex CLIなどのエージェント。

## ビルドと確認

```bash
./script/check.sh
./script/build_and_run.sh --build
./script/build_and_run.sh --demo
```

通常起動は `./script/build_and_run.sh`。アプリは `~/Applications/会議の相棒.app` に配置され、`dist/MeetingSidekick.app` からも開けます。`--build` も配置済みアプリを更新するため、現在の作業用アプリを残したい場合は `swift build` のみを使ってください。`MEETING_BUILD_PATH` でコンパイル用ディレクトリを分離できます。

デモは録音や外部AIを使わず、架空の文字起こしで動作を確認します。テストは実マイクの認識精度やiPhoneへの音声到達を保証するものではありません。

## キーと個人データ

設定画面から入力したAPIキーはmacOSキーチェーンに保存します。環境変数、またはこのリポジトリ直下の `.env.local` も利用できます。必要なら `.env.example` をコピーし、自分のキーをローカルで入力します。

`Runtime/` に設定と会話の状態、`Prototypes/` に制作物を保存します。これらと `.env.local`、ビルド生成物はGitの対象外です。実際の会話をテストやドキュメントに貼り付ける場合も、個人情報を取り除いてください。音声AIへの呼び出しでは選択した入力の音声が外部サービスに送られ、画面共有を有効にすると画面も送られます。文字起こし・文脈も、実行する判断・思考・制作処理に渡されます。

## 使い方

1. 「一緒に聞く」を押し、初回の「声の接続」でMacかiPhone・会議側の入力を選びます。
2. 「サイドキック、今日は旅行アプリの相談」のように、呼び名と話題を声で伝えます。
3. 「サイドキック、聞くだけにして」「サイドキック、今日は終わり」などで参加を操作します。

ウィンドウを閉じてもメニューバーに残ります。「会話を見る」で文字起こしを確認できます。音声の入力メーター、認識した言葉、返答テストは「声の接続」にあります。

iPhoneを同じMeetに参加させる場合は、Mac側でMeetのアプリ音声を取り込みます。iPhoneへ返事を返すには仮想オーディオ出力とMeetのマイク設定が必要です。Macの既定出力で聞こえることと、iPhoneで聞こえることは別の確認です。Meetの設定は自動変更しません。

## 現在の制約

- 日本語文字起こしはAppleの端末内認識を使用します。長い発話の誤認識は未解決です。追加の専門語モデルが準備できない場合は語彙ヒントで開始します。
- Gemini Liveを中心に実装しています。OpenAI Realtimeへの切り替えは実装済みですが、実APIでの検証は未完了です。画面理解とiPhone・Meetを経由する継続した音声往復も追加検証が必要です。
- スマートフォン単独の常時録音アプリではありません。MeetやDriveの録画・保存も自動管理しません。
- Codexの要求モデルと実際に使われたモデル、検索設定と実際に観測した検索イベントを区別します。契約・APIの利用料金や上限は各サービスに従います。
- ローカルビルドはアドホック署名です。更新後にmacOSの録音・画面収録権限を再確認する必要が生じることがあります。安定した配布署名・公証は未対応です。

## 構成

`MeetingCore` は判断と設定、`MeetingServices` は外部AI・エージェント接続、`MeetingMac` は音声取得とUIを担当します。`MeetingChecks` は回帰チェック、`MeetingProbe` は診断用です。

```text
マイク / Meet音声 / 認証されたモバイル文字起こし
  → TranscriptEvent
  → 音声コマンド または Jev判断
  → 実行条件・重複・停止世代の確認
  → 待機 / 音声会話 / 用語調査 / 思考・計画 / 試作
```
